# 波形の周期による音声の時間圧縮・伸長を追加する

- Completed: {YYYY-MM-DD}
- Branch: feature/add-playout-time-stretch
- Polished: 2026-10-01

## 目的

音声の再生で到着の間隔が揺らぐと、目標の時刻どおりに鳴らせない音が出る。遅れて届いた音を捨てると音が途切れるため、波形の周期 (ピッチ) 1 つ分を削ってクロスフェードで繋ぎ、目標の時刻へ戻せるようにする。将来の隙間の補間で使う時間伸長も同じ仕組みで作る。

moqt-rs には音声の時間伸縮が無く、examples は復号済みの音声をそのまま出力へ渡している。波形だけを使う純粋な処理として、no_std / Sans-I/O の規約の中で実装する。

## 現状

- `src/` に音声の時間伸縮の実装が無い
- `examples/moq-sub/src/decoder.rs` の `DecodedAudioFrame` は S16 interleaved PCM を保持する。再生側は `raw_player::AudioPlayer` へ渡しており、音の長さを変える経路が無い
- moqt-rs は `#![no_std]` + `alloc` のクレートであり、`core` に無い浮動小数メソッド (`floor` / `ceil` / `round` / `trunc` / `sqrt` / `log10` / `powf` など) は使えない。`f32::abs` / `min` / `max` / `signum` / `copysign` は `core` にある
- `.github/workflows/ci.yml` は `thumbv7em-none-eabihf` 向けの no_std ビルドを確認している

## 設計方針

`src/playout.rs` (親モジュール) と `src/playout/stretch.rs` を追加し、`src/lib.rs` に `pub mod playout` を足す。第 1 チャンネルの波形だけを使い、他のモジュールに依存しない。

### 公開する処理

- チャンネルごとの f32 スライスとサンプルレートを受け取り、時間圧縮と時間伸長を行う
- 戻り値は長さの変化 (サンプル数)。圧縮は負、伸長は正、操作しなかったときは 0 とする
- 圧縮は入力を詰めた結果を同じバッファへ書き、呼び出し側は元の長さに変化を足した範囲を使う。伸長は呼び出し側が用意した出力バッファへ書く。ホットパスでヒープ確保を強制しない

### ピッチの周期の探索

- 第 1 チャンネルを 4 kHz へ間引く。サンプルレートごとの FIR 係数 / 間引き率 / 遅延補正は次のとおり (係数は和で正規化して使う)
  - 8 kHz: `[1229, 1638, 1229]` / 2 / 2
  - 16 kHz: `[614, 819, 1229, 819, 614]` / 4 / 3
  - 32 kHz: `[584, 512, 625, 667, 625, 512, 584]` / 8 / 4
  - 48 kHz: `[1019, 390, 427, 440, 427, 390, 1019]` / 12 / 4
- 係数の和で正規化し、フィルタ長 - 1 + 遅延の位置から間引きの間隔ごとに取る
- 間引いた信号の相関を、4 kHz の 10 から 60 のずらし幅で求める (2.5 ms から 15 ms)。相関の窓は 50 サンプル (12.5 ms)。ずらし幅 0 は探索しない
- ずらし幅の上限は `min(60, 間引いた信号の長さ - 50)` とする。上限が 10 未満のときは操作しない (音が短すぎて周期を求められない)
- 最も相関が強いずらし幅を元のサンプルレートのサンプル数へ戻したものをピッチ周期とする

### 操作する条件

- 切れ目の前後 (ピッチ周期ぶん) の正規化相関を求める。`sqrt` を使わず、二乗の比較で判定する (`dot > 0` かつ `dot * dot >= 0.9 * 0.9 * energy_before * energy_after`。集計は f64)
- 相関が 0.9 以上のときだけ操作する。0.9 未満でも、全チャンネルの振幅のピークが 0.001 (マイナス 60 dBFS 相当) 未満の音は操作する (無音は詰めても伸ばしても聞こえない)
- 操作する位置は音の中央 (長さ / 2) とする
- ピッチ周期が音の中央に収まらない入力、対応外のサンプルレート、空の入力では操作しない

### 時間圧縮と時間伸長

- 時間圧縮はピッチ周期 1 つ分を削り、時間伸長はピッチ周期 1 つ分を挿す
- 切れ目の前後はピッチ周期ぶんのクロスフェードで繋ぐ。重みは 1 サンプルごとに `1 / (fade + 1)` ずつ動かす
- 長さの変化 (サンプル数) を返す (圧縮は負、伸長は正)

## 完了条件

- 周期的な波形の入力で、時間圧縮するとピッチ周期 1 つ分が詰まり、時間伸長するとピッチ周期 1 つ分が増えること
- 相関が 0.9 未満で無音でもない入力では長さが変わらないこと。無音 (ピーク 0.001 未満) では相関に関係なく操作されること
- 8 kHz / 16 kHz / 32 kHz / 48 kHz で動くこと。対応外のサンプルレートでは操作されないこと
- クロスフェードの重みを含め、操作後の波形が期待値と一致すること (テストで固定する)
- モノラルとステレオ、空の入力、音が短すぎる入力で panic せず、短すぎる入力は操作されないこと
- `make test` (`cargo test --workspace`) と `make clippy` と `make fmt` が通ること
- `cargo build -p shiguredo_moqt --target thumbv7em-none-eabihf` が通ること
